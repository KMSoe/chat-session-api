# Project Set up 
1) git clone https://gitlab.visibleone.io/laramaster/oneotoo.git
2) cd project_folder 
3) run composer install
4) copy .env.example to .env 
3) run php artisan key:generate
5) run php artisan breeze:install
6) run php artisan migrate
7) run npm install
8) npm run dev
9) run php artisan db:seed --class=UserSeeder
